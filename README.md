## 搬瓦工到底卖的是什么？VPS 是什么概念？

VPS，全称 Virtual Private Server，中文叫"虚拟私人服务器"。

简单说，就是把一台物理服务器通过虚拟化技术切成多个独立的小机器，每个人租一块，互不干扰，拥有完整的 root 权限和独立 IP 地址。你可以在上面装任何 Linux 系统，部署网站、跑程序、搭服务，和租了一台真实服务器没什么区别——只是价格便宜很多。

搬瓦工卖的就是这种东西。它是"自托管"模式，买了之后一切靠自己管，没有客服帮你装软件、没有人帮你配服务。正因如此，价格压得比较低。
